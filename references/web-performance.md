# 网页轻量化

用于单方案和多方案网页。目标是在手机和电脑上及时显示包装，并可反复切换平面与 3D。

## 资源准备

- 保留高清原稿和可编辑模型，生成单独的网页专用资源。纹理分辨率按实际显示与放大需要选择，先从约 2048 px 长边试起，检查品名、小字、条码和边缘后调整。
- 不需要透明的颜色贴图可用高质量 JPEG；平面刀版可用保留透明的 WebP。有真实透明材料或镂空时保留相关 alpha，不因压缩改变材料。
- 裁去无用边距必须同步映射所有实际使用的 UV，不裁掉印刷面；对齐原稿、模型和平面展示。压缩后检查尺寸、几何、法线、材质、正反面与颜色。
- 导出只含产品。网页不要求引入在线压缩解码器。优先通过图像压缩、合理网格与按需加载减小体积。
- 记录 GLB、内嵌贴图尺寸、平面图、首屏资源体积的优化前后数值。数值由本项目实测，不把示例体积当固定标准。

## 加载与切换

- 首屏只请求当前场景必需模型与本地运行库。平面图首次进入时加载，单独展示模型首次点击时加载。原稿和摄影棚资源留在交付目录。
- 折叠模块、配置和面片在桌面需要动画时再创建。手机及触屏默认直接切换，系统减少动态效果时直接切换。
- 桌面折叠采用足够的小面板坐标和图像，按相同比例换算画布、边界与折轴。切换结束释放临时 DOM 和合成层，避免反复切换积累资源。
- 加载失败时保留清晰状态，释放切换锁，并允许重试。检查首次加载完成前切换、快速连续点击和返回时的行为。
- 新版资源使用版本参数或指纹。预览与发布需检查最新入口及资源，网页 ZIP 与实际发布目录一致。

## 验证与确认

桌面检查首次加载、平面与 3D 双向动画及清晰度。手机检查首次进入平面、返回 3D、单独展示和全屏，再连续切换多轮。必要时采用 CPU、网络降速和高设备像素比复核，观察报错、无响应、内存与图形上下文异常。

浏览器模拟与真实手机分别记录。模拟未出现问题不宣称实体手机已通过。测试后将可查看版本、体积与已执行检查交使用者确认；未通过时留在网页步骤修正。

## 生成网页副本

使用 scripts/prepare_web_assets.py 的 --model、--dieline 和 --out 参数生成新目录中的 model.glb、dieline.webp 与 web-assets.json。脚本依赖 Pillow，只调整嵌入的颜色贴图和平面图，保留几何、UV 和材质参数；alpha 材质保留 PNG。按需要用 --texture-edge、--flat-edge、--quality 调整后复核。脚本不自动判断图稿清晰度；完成后需要展示实际网页效果给使用者确认。

单方案可将输出交 build_viewer.py；多方案分别准备后填入 build_comparison.py 的配置。原稿压缩前后均单独保留。
