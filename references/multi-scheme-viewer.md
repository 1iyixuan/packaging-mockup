# 多方案共同展示

仅在使用者要求多方案时使用。单方案采用原单方案模板。

## 输入与换稿

先确认方案数量、名称、版本和各自图稿。逐项核对盒型、尺寸及材质是否共用。同盒型换稿复用几何和已确认结构，分别对齐 UV。每个方案的模型、平面图和折叠数据对应稳定 ID；换稿后同步更新该方案的三类资源。用户更正归属后，按其最后确认的对应更新。

## 共同场景

- 首屏把所有方案放在同一个 3D 场景，统一照明和背景。模型之间无可见分区、编号或画布边框，保留合理间隔，旋转和缩放时检查模型边角。
- 鼠标悬停命中的包装微微放大约 4%–5%，移开恢复。仅改变命中包装的反馈倍率。
- 直接拖盒只旋转该盒。拖空白处，以最近单独旋转的包装为基准统一角度，再同步旋转所有包装。缩放时用滚轮或双指同时缩放全部包装。
- 用实际模型命中检测区分盒面和空白。区分点击与拖动，拖动或双指操作结束时不触发单独展示。

## 单独展示与返回

点击包装进入对应方案的单独展示，保留旋转、缩放、平面定位缩放和平移、Home、桌面折叠和全屏。左上标题第二行从“包装展示”变成“返回”。点击返回恢复进入前共同场景的视角和倍率。

全屏时保留“返回”和右上退出全屏。返回共同场景后继续全屏。手机点按与桌面点击采用相同的方案对应。

平面模式显示对应真实展开图；多方案平面可并排比较，单独展示时只显示该方案。手机使用直接切换，桌面按各自真实折线展开和折回。

## 构建与检查

使用 scripts/build_comparison.py 的 --config 和 --out 参数构建共同场景网页。配置含标题、字幕和 schemes 数组，每项含稳定 id、显示 name、model、dieline、fold_config，路径相对配置文件。dimensions_mm 为共用模型的宽深高。本模板用于盒型、单位与正面方向一致的模型；其他组合需按其资料调整取景和布局。

单方案继续使用 scripts/build_viewer.py。两类网页都执行网页轻量化和每步确认。模板只能表达已经确认的结构与图稿；输入不足时先索取。

检查从任意盒面移至另一盒及空白时的反馈、先单独旋转再联动、同步缩放、逐方案进入与返回、全屏返回，以及各方案的贴图、平面图和折叠归属。新增或换稿只重新检查受影响部分和关联交互。

配置示例，文件路径替换为本项目已确认的资源，dimensions_mm 替换为已确认的尺寸：

~~~json
{
  "title": "产品名称",
  "subtitle": "包装展示",
  "dimensions_mm": [100, 30, 150],
  "schemes": [
    {"id": "a", "name": "方案一", "model": "a/model.glb", "dieline": "a/dieline.webp", "fold_config": "a/fold.json"},
    {"id": "b", "name": "方案二", "model": "b/model.glb", "dieline": "b/dieline.webp", "fold_config": "b/fold.json"}
  ]
}
~~~

省略 fold_config 时该方案使用直接切换；仅在用户确认该展示范围后采用。尺寸数组是参数格式示例。
