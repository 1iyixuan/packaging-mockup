# 网页模板、验证与部署

## 参考与布局

以 `assets/viewer/` 为默认布局。背景为 `#eee`，包装居中且无投影，左上是深灰两行标题，左下为带方框和立方体图标的模式切换按钮，右上为全屏按钮。常态保留留白；全屏只保留当前展示和退出图标。按项目实际模型调整标题、取景和曝光。使用系统字体和本地资源。

## 生成源码

使用可用 Python 3（脚本仅依赖标准库）：

```text
python SKILL_DIR/scripts/build_viewer.py --model OUTPUT/model.glb --title "产品名称" --subtitle "包装展示" --dieline OUTPUT/平面预览.jpg --fold-config OUTPUT/fold.json --out OUTPUT/网站源码
```

平面预览使用本项目真实展开稿导出的 PNG、JPEG 或 WebP，保留页片轮廓、折线及可读细节。可用 `--poster` 指定加载占位预览，`--orbit "-26deg 77deg 75%"` 和 `--mobile-orbit "-26deg 77deg 128%"` 调整初始取景。单行标题省略 `--subtitle`。只做模型展示时省略平面图和折叠配置；已同意直接切换时可仅提供平面图。

脚本校验 GLB 及折叠配置，复制本地运行资源，生成带资源版本的网页和相邻的 ZIP。输出路径选择新的或空的目录。脚本只构建本地文件。

`vendor/model-viewer.min.js` 为官方 Google model-viewer 的固定版本副本；版本、npm 完整性与哈希记在库的 provenance 文件。更新依赖时从官方包仓库获取，保留许可证并重新验证。若本地库缺失，不用 CDN 偷换：恢复该依赖后再构建。

网页需 HTTP 服务，双击 file:// 可能无法加载模块和模型。代理运行环境须确认浏览器与本地服务在同一主机或使用支持的转发；不能把另一台机器的 127.0.0.1 当成用户可访问预览。

## 按刀版配置展开和折回

矩形纸盒使用模板的平面面板和直线折轴。将 GLB 正面朝向初始相机且保持竖直。在导出的平面预览图上测量正面、侧面、背面、顶底页片和粘口的边界及折线。以图片左上为原点，x 向右，y 向下。可以等比缩小坐标，`artwork` 和所有坐标必须使用同一比例，宽高比与预览图一致。

下面仅示意面板格式，实际配置需覆盖本项目全部参与折叠的面板。

```json
{
  "artwork": [1000, 600],
  "panels": [
    {"bounds": [100, 160, 420, 440]},
    {"bounds": [420, 160, 520, 440], "parent": 0, "hinge": [420, 160], "axis": "Y", "angle": 90, "timing": [0.22, 1]},
    {"bounds": [100, 60, 420, 160], "parent": 0, "hinge": [100, 160], "axis": "X", "angle": 90, "timing": [0, 0.62], "outline": "0% 100%, 4% 0%, 96% 0%, 100% 100%"}
  ]
}
```

- `bounds` 为左、上、右、下边界。第一项为固定正面，其他面板按连接顺序引用先定义的 `parent`，索引从 0 开始。
- `hinge` 为与父面板相连的折线上的一点，横线用 `X`，竖线用 `Y`。 `angle` 是成盒时的带符号角度，展开时逐渐回到 0。按实际折向检查纹理朝向、面板接缝及页片重叠。
- 可选 `outline` 使用面板自身百分比坐标裁出不规则页片。可选 `timing` 指定面板在整段展开进度中的起止点，默认 `[0, 1]`。折回沿同一轨迹反向播放。
- 比对合起时的动画和 GLB 的正面方向、轮廓、取景及比例，并检查展开结束时与静态平面图对齐。弧形或软袋结构按真实结构定制动画。需要折叠但依据不足时，先索取缺失资料。

## 交互与质量检查

1. 桌面首屏核对标题、模型实际加载、浅灰背景、无投影、主体居中和留白。检查左下图标及文字悬停时只轻微放大，右上图标可进入和退出全屏。
2. 3D 拖动可查看背面、左右、顶底，滚轮可缩放，Home 回到初始视角。
3. 平面在展开图偏离中心处滚动，确认指针下的图稿位置保持稳定；按住拖动可平移，无旋转或倾斜。Home 恢复居中和倍率。
4. 测试展开与折回各一次，核对纹理与折线、反向动画、平面交互恢复。开启减少动态效果后检查直接切换。
5. 进入全屏时检查标题与模式按钮隐藏、退出图标可见，退出后界面恢复。手机验证 390×844 和横屏，检查单指拖动、双指缩放及标题、包装、按钮无溢出。触摸模拟与实机检查分开记录。
6. 检查运行资源请求及浏览器错误，确认当前页面用到最新资源版本；用户可见页面仍显示旧样式时核对所开地址、版本和缓存。断开外网或拦截外部请求验证自包含。检查加载失败提示和 ZIP 解包完整性。

模型材质在网页和 Blender 中需分别检查；不得声称复杂 Blender 节点可无损变成网页材质。设备模拟结果与物理手机检查分开记录。

## Netlify Drop（推荐）

1. 准备已通过本地验证的静态网页输出目录，例如 `dist` 或 `网站源码`。根目录应有 `index.html`，保留网页运行所需的 JS、GLB、平面预览图和折叠数据。印刷原稿、`.blend`、个人路径、日志和密钥留在交付目录。
2. 新建网站时，在浏览器中登录 Netlify，确认目标团队，打开 [Netlify Drop](https://app.netlify.com/drop)。更新已有网站时，打开目标项目的 **Deploys** 页面，使用该项目的拖拽区发布新版并保留原站点地址。
3. 在 Windows 文件资源管理器里选中本次的输出文件夹，把整个文件夹直接拖到网页的虚线区域。蜜雪拿铁项目的示例路径是 `E:\李懿轩\Codex平面\sites\mixue-latte-packaging-360\dist`，其他项目使用各自的输出目录。工具无法完成拖拽时，把实际目录路径和 Drop 入口交给用户操作。
4. 等待发布完成，从 Netlify 复制实际返回的 `https://xxx.netlify.app` 地址。打开地址检查页面、模型、贴图和交互。若交付要求公开分享，用无痕窗口确认访客无需登录或密码即可打开。站点由 Netlify 托管，电脑关机后仍可访问。链接的持续可用性取决于站点及托管状态。未登录发布时，按页面提示及时认领临时站点。认领后的访问范围取决于项目可见性。
5. 把实际链接及验证结果写入项目的 `交付记录.md`。有大陆实际网络测试才记录为大陆访问已验证。交付时同时保留原文件、源码目录和 ZIP。

官方说明见 [Netlify Drop 快速入门](https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/)。
